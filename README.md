# ⚙️ Machine Learning System for Early Detection of Equipment Failure

## 📌 Project Overview

The **Machine Learning System for Early Detection of Equipment Failure** is a predictive maintenance project developed as part of the Infosys Springboard Internship.

The project uses machine learning techniques to analyze industrial machine sensor data and predict potential equipment failures before they occur.

By analyzing parameters such as air temperature, process temperature, rotational speed, torque, and tool wear, the system identifies patterns that may indicate machine failure.

The main objective is to help industries reduce unexpected machine breakdowns, minimize maintenance costs, improve productivity, and increase equipment lifespan.

## 🎯 Project Objectives

- Analyze industrial machine sensor data.
- Perform Exploratory Data Analysis (EDA).
- Identify missing values, duplicates, and outliers.
- Understand relationships between sensor readings and machine failures.
- Train a Machine Learning model to predict equipment failure.
- Evaluate model performance using suitable evaluation metrics.
- Identify important features influencing machine failure.

## 📊 Dataset

**Dataset:** AI4I 2020 Predictive Maintenance Dataset

The dataset contains industrial machine operating conditions and failure records.

### Important Features

| Feature | Description |
|---|---|
| Air Temperature | Temperature of surrounding air |
| Process Temperature | Temperature during machine operation |
| Rotational Speed | Machine rotation speed in RPM |
| Torque | Rotational force of the machine |
| Tool Wear | Amount of tool usage in minutes |
| Machine Failure | Indicates whether machine failure occurred |

The dataset also includes different failure categories such as:
- Tool Wear Failure (TWF)
- Heat Dissipation Failure (HDF)
- Power Failure (PWF)
- Overstrain Failure (OSF)
